# RAG 分阶段实验与评测协议

本文件规定后续领域语料实验的口径，不表示这些实验已全部完成。现有32父块与400题开发集、64题挑战集的结果继续单独保留。

## 语料扩充依据

| 阶段 | 参考规模 | 需要解决的问题 | 升级依据 |
|---|---|---|---|
| 一 | 约500个有效块 | 解析、索引、检索、证据、生成和评测全流程 | 资料来源可追踪，主要解析错误已抽检，问题和证据可核验 |
| 二 | 约1000—2000块 | 不同文档、问题与证据类型的覆盖 | 覆盖不足有记录，新增文档能填补实际缺口 |
| 三 | 按需要，可至约5000块 | 规模增长对效果、延迟与成本的影响 | 在去重与质量不退化的前提下，确有覆盖或容量实验需求 |

数量不构成阶段通过标准。每阶段提供来源/版本清单、文档家族与问题类型覆盖、近重复检查、解析抽检及无效块记录。不能用重复文档、机械缩小切块或噪声增加规模。

项目重点是检索、证据问答与可靠评测。CLI或轻量API足以承载实验；分布式存储、多租户、复杂调度和大规模服务化不作为必选项。需要扩充工程功能时，先说明它解决的实际问题与验证方法。

## 实验顺序与控制变量

1. Dense：固定一个简单切分方案，记录Embedding与距离配置。
2. BM25：使用相同语料、返回单元和gold作为独立基线。
3. Hybrid+RRF：固定通道候选数，在开发集确定融合参数。
4. Hybrid+RRF+Reranker：使用同一批候选，测重排收益与额外耗时。
5. 父子索引：若错误集中在块过大、主题混合等问题，单独变更检索单元；gold仍落在同一证据/返回单元上。
6. Query Rewrite：若错误集中在指代、自然长问法或表达差异，单独加入；记录改写错误、额外token及延迟，不同时改变切分与重排。

每步保留前一版本作为消融对照。当前父子索引作为既有分支保留，不能把它隐含进所有新基线。固定候选池的Reranker无法恢复未被召回的证据；同时报告候选Recall@N和重排后Recall@K，把候选漏召回与排序错误分别归因。

## 标注与测试隔离

每题记录question_id、问题类型、是否可回答、适用文档版本、参考答案、证据片段、相关块集合和分级相关性。多证据题记录“共同必要”的证据组，允许不同但等价的证据集合；不能把同文件所有块都当作相关证据。

语料去重和事实/模板/文档家族隔离先于划分。训练或调参只使用开发集，封存测试集的题目、gold和哈希固定。已分析的64题只作诊断/回归，不能重复当作未知测试。证据支持不明确、答案可能不存在或版本不确定的题先人工复核，不强行标注。

## 指标口径

| 层次 | 指标 | 判定与分母 |
|---|---|---|
| 检索 | Recall@K | topK命中的相关块数/已标注相关块数；单独提供Hit@K，不能把二者在多证据题上混为一谈 |
| 检索 | Precision@K | 相关返回块数/实际返回块数，同时报告返回不足K的比例；不足K按K作分母的版本必须另名说明 |
| 排序 | MRR@K | 首个相关块名次的倒数，K外或未命中记0，按题平均 |
| 排序 | nDCG@K | 使用人工分级相关性，例如0无关/1辅助/2直接证据；按同一标注集合计算理想DCG，未充分标注的候选不直接当成无关 |
| 生成 | Correctness | 依据参考答案判定事实正确与必要信息完整；可回答题以全体为分母，误拒不因没有生成而排除 |
| 生成 | Faithfulness | 答案中的可核验主张有多少被所给证据支持；与答案本身正确性分开评审 |
| 引用 | Citation Precision | 引用的证据与其所附主张之间，支持关系成立的比例；编号存在不等于支持成立 |
| 引用 | Citation Recall | 需要引用的主张中，有充分支持引用的比例；另报参考答案关键证据覆盖，防止遗漏关键内容却获得高引用覆盖分 |
| 拒答 | FRR / FAR | 分别记录检索准入层与最终生成层；库内错误拒绝/全部库内，库外错误放行或作答/全部库外 |
| 性能 | Latency | 编码、各召回通道、融合、重排、改写、生成及总耗时；记录冷/热启动、并发、硬件、P50/P95与错误率 |
| 成本 | Token Cost | 实际输入/输出token、改写/生成/评判的调用数；记录价格日期与币种，先报告token再换算，不能凭空估计 |

空答案、超时、模型错误、引用无效、无答案题应单独分类。没有可评主张的拒答不能自动获得Faithfulness满分；无引用的回答在有待引用主张时，Citation Recall为0，Citation Precision标为不可计算并单列无引用率。聚合时报告适用样本数，避免只保留成功回答。

检索分开报告可回答题和各题型；无答案题不进入需要gold证据的召回分母。多证据题增加“证据组是否完整命中”，避免只找到其中一块就算成功。问答最终FAR要按“是否给出无依据答案”判断，不能沿用检索放行率替代。

## 可信度与发布

人工审核参考答案、分级相关性和引用支持关系，保留判据与分歧复核记录。LLM-as-judge作辅助时记录模型、提示词、温度、版本及与人工一致性，不用另一个模型的打分当作绝对真值。

同一封存集进行成对比较，给出样本数与不确定性；不凭单点小幅波动宣称提升。报告应包含覆盖表、控制变量、逐题结果、错误类型、效果/延迟/成本及代码/语料/题集哈希。无收益的组件也保留实验记录，不进入默认链路。

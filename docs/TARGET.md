# RAG 项目深化与验收清单

本项目独立管理资料、模型、索引与评测，重点是知识质量、检索效果和证据问答。CLI或轻量API足以承载，不要求大型分布式系统。

1. 约500个高质量块验证链路，按文档和问题类型覆盖扩展至1000—2000，需要规模实验时才扩展至约5000，不凑数量。
2. 记录来源、许可、版本、标题和页码；抽检解析与近重复；人工核验参考答案、证据和相关块集合。
3. 冻结语料和gold，按Dense、BM25、Hybrid+RRF、Hybrid+RRF+Reranker逐步消融，分报候选Recall@N与最终Recall@K。
4. 父子索引和Query Rewrite按失败类型分别验证，记录收益、延迟、token和成本；候选集没有的证据无法靠重排找回。
5. 按事实、模板和文档家族隔离评测；开发集、诊断集和新封存测试集用途分开，封存测试不选参。
6. 按EVALUATION_PROTOCOL.md补齐检索、生成、引用、拒答与成本指标，人工复核引用支持与判分分歧。
7. 优先分析长问法误拒、硬负例误接受、版本冲突与多证据缺失；无稳定收益的组件不进入默认链路。
8. 留存数据卡、代码/模型/题集哈希、配置、逐题结果与失败归因；能独立解释BM25、RRF、归一化距离、gold与三个真实失败链路。

当前基础检索、索引生命周期和规则闸门已完成；领域语料扩展、重排、查询改写及完整生成/引用语义评测仍需逐步实施。
